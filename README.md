# 계란 100개당 생산비 분석

1998년부터 2025년까지 계란 100개당 생산비, 주요 비용 항목, 사육 규모별 차이를 살펴보는 브라우저 기반 대시보드입니다.

## 실행 방법

`index.html`을 최신 브라우저에서 열면 됩니다. 별도의 패키지 설치나 서버 실행 없이 사용할 수 있습니다.

## 파일 구성

- `index.html`: 대시보드 화면과 문서 구조
- `style.css`: 화면 및 인쇄 스타일
- `app.js`: 차트, 표, 지표 계산과 화면 동작
- `data.js`: CSV 원자료에서 변환된 연도별 데이터
- `convert.js`: 같은 폴더의 CSV 파일을 읽어 `data.js`를 다시 생성하는 Node.js 스크립트
- `계란_100개당_생산비_*.csv`: KOSIS에서 받은 기간별 원자료

## 데이터 갱신

1. 새 CSV 파일을 프로젝트 폴더에 추가하거나 기존 CSV를 교체합니다.
2. Node.js가 설치된 환경에서 프로젝트 폴더에 들어갑니다.
3. 다음 명령을 실행합니다.

```bash
node convert.js
```

폴더에 있는 모든 `.csv` 파일을 이름순으로 읽어 연도·사육 규모별 JSON 데이터를 `data.js`에 기록합니다. 각 CSV는 첫 행에 연도, 둘째 행에 사육 규모 구간, 이후 행에 항목별 값이 있는 현재 원자료 형식을 따라야 합니다. 각 연도에 `평균` 열도 필요합니다.

## 자료 및 해석

자료는 프로젝트에 포함된 KOSIS 「농축산물생산비조사」 계란 100개당 생산비 CSV 5개(1998–2025년)를 합친 것입니다. 연도별 사육 규모 구간이 변경되므로 규모 간 비교는 해당 연도 안에서 해석해야 합니다. 표와 차트는 CSV의 평균값과 항목 값을 그대로 사용합니다.
